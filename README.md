# Together Quest

Интерактивный планировщик общей цели для пары или небольшой команды. Большая цель
разбивается на последовательные уровни и короткие задачи, а прогресс поддерживается
XP, наградами, общей копилкой и заметками.

## Что можно попробовать

- менять страну или формулировку главной цели;
- добавлять участников и персональные задачи;
- отмечать выполненные шаги и накапливать XP;
- вести общую копилку;
- оставлять заметки и поддержку;
- сбрасывать демоверсию через меню.

Публичная версия работает без регистрации. Данные каждого посетителя сохраняются
только в его браузере через `localStorage`, поэтому действия одного пользователя
не меняют демонстрацию для остальных.

## Продуктовая идея

Обычный список задач хорошо хранит дела, но плохо поддерживает длинную совместную
цель. Together Quest превращает путь к поступлению или переезду в понятный маршрут:
показывает ближайший доступный уровень, фиксирует вклад каждого участника и даёт
маленькую награду за завершённый шаг.

Первый сценарий — подготовка пары к переезду и обучению в другой стране.

## Технологии

- Next.js 16;
- React 19;
- TypeScript;
- адаптивный CSS;
- браузерное хранение состояния;
- GitHub Actions и статический экспорт для GitHub Pages.

## Локальный запуск

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000`.

## Проверка production-сборки

```bash
npm run build
```

Готовая статическая версия появится в каталоге `out`.
