# Together Quest

Интерактивный MVP AI-агента для пары или небольшой команды. Пользователь описывает
общую цель естественным языком, отвечает на контекстные вопросы, а агент превращает
ввод в последовательный маршрут: этапы, базовые задачи, зависимости и распределение
ответственности.

## Что можно попробовать

- выбирать сценарий: переезд, свадьба или свободная цель;
- получать разные уточняющие вопросы для каждого сценария;
- наблюдать этапы работы AI-агента и предварительно проверять созданный план;
- генерировать персональный маршрут под страну, формат свадьбы, срок и бюджет;
- добавлять участников и персональные задачи;
- отмечать выполненные шаги и накапливать XP;
- вести общую копилку;
- оставлять заметки и поддержку;
- сбрасывать демоверсию через меню.

Публичная версия работает без регистрации. Данные каждого посетителя сохраняются
только в его браузере через `localStorage`, поэтому действия одного пользователя
не меняют демонстрацию для остальных.

## Продуктовая идея

Обычный список задач требует, чтобы пользователь уже понимал весь путь. Together
Quest начинает раньше: помогает превратить неструктурированное «мы хотим…» в
первую рабочую версию плана. Агент распознаёт сценарий, учитывает контекст,
дробит крупные действия и предлагает распределение между участниками. Пользователи
могут отклонить, изменить или дополнить каждую задачу.

Первые предметные сценарии — совместный переезд и подготовка свадьбы.

## Как показан AI в MVP

Текущая публичная версия демонстрирует продуктовый сценарий агента с помощью
детерминированной клиентской генерации: тип цели и параметры действительно меняют
этапы, тексты задач и распределение. Внешняя модель не вызывается, поэтому
пользовательские данные не покидают браузер.

Следующий технический этап — подключить модель через серверный слой, добавить
структурированный JSON-ответ, проверку схемы, безопасную фильтрацию входных данных,
редактирование предложений и retrieval из проверенных источников для регулируемых
сценариев. Юридические, визовые и финансовые решения агент не принимает.

- Next.js 16;
- React 19;

## Локальный запуск

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000`.

## Проверка production-сборки

```bash
npm run build
```

Готовая статическая версия появится в каталоге `out`.

## Статус

Это проверяемый MVP для демонстрации продуктовой гипотезы, UX взаимодействия с
агентом и адаптивной генерации маршрута. Для коммерческой многопользовательской
версии нужны аутентификация, раздельные рабочие пространства, серверное хранение,
управление доступом, модельный API, журналирование и оценка качества планов.
